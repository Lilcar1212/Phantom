# Hollow Oath: 3D asset production

Game-ready Blender assets for **Hollow Oath**, an Edo-inspired anime action RPG on Roblox. Every asset is generated by a Python script running headless Blender (`bpy`), so each one can be rebuilt, tweaked and re-exported the same way every time.

* `MANIFEST.md`: every exported file (triangles, textures, pivot, checks). Use this for Roblox import and placement.
* `docs/PIPELINE.md`: FBX export settings, Roblox import steps, conventions and checks. **Start with the scale test cube.**
* `docs/PHASE1_PLAN.md`: build order and status.
* `docs/layout/`: city layout plan (image + JSON).

```
assets/<Phase>/<Category>/HO_*.fbx     exported meshes
textures/<Set>/HO_T_<Set>_*.png        shared 1024² PBR sets (SurfaceAppearance)
renders/<Phase>/<Category>/*.png       preview renders (3/4, front, ...)
scripts/                               one script per asset family
tools/                                 pipeline: ho.py (export/checks/render), geo.py (mesh builder), roofkit.py, ...
```

Setup: `pip install bpy pillow scipy matplotlib` (Python 3.11).
